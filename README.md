# Korgan Intelligence

Локальный агент мониторинга науки, технологий и стартапов для macOS Apple Silicon.

## Быстрый старт

```bash
cd "/Users/amanatkorgan/Desktop/my projects/my news AI"
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m app --once
```

Без `OLLAMA_MODEL` агент работает в режиме сбора и формирует резервный текст без выдуманных фактов. Для локальных пересказов установите Ollama и загрузите модель 3B–4B, например `ollama pull qwen2.5:3b`.

Для Telegram-канала заполните `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, один раз выполните `python -m app --authorize`, затем `python -m app --list-dialogs`; выбранный ID канала или `@username` укажите в `TELEGRAM_TARGET`. Числовые варианты channel ID с/без префикса `-100` поддерживаются. Секреты и сессия остаются локально.

Установка фонового запуска: `./scripts/install_launchd.sh`.

Агент идемпотентен: SQLite хранит статьи, выпуски и идентификаторы Telegram. Межпроцессная блокировка не позволяет двум циклам одновременно собирать и отправлять один выпуск. Папка `news/` в корне проекта содержит JSON-снимок последнего цикла: все собранные материалы, выбранные статьи и текст выпуска. Эти файлы очищаются через 24 часа вместе с временными данными. Тематический профиль и веса находятся в `config/interests.yaml`. Для явного разового теста с немедленной отправкой используйте `python -m app --test-send-now`.

## Проверки и ограничения

`python -m pytest -q` запускает локальные тесты без реальной отправки в Telegram. В текущем окружении обнаружена Ollama 0.34.4, но модель не загружается автоматически: задайте `OLLAMA_MODEL` и установите выбранную модель вручную после проверки размера.

Telegram API ID, API hash, целевая группа и факт авторизации отсутствуют, поэтому реальное планирование сообщений ещё не подтверждено. Укажите их в `.env`, выполните `python -m app --authorize`, затем тестируйте на отдельной группе.

Текущая версия отправляет только ближайший выпуск. Она не создаёт пропущенные выпуски задним числом и сохраняет локально подготовленный выпуск, если Telegram не настроен. Telethon поддерживает параметр `schedule` в `send_message`, а Telegram добавляет такое сообщение в серверную очередь; совместимость с конкретной группой нужно проверить на тестовом чате. Для полного production-ввода остаётся проверить права целевой группы и фактическое принятие сообщения аккаунтом.
